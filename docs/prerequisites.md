# Prerequisites for Grid Feeding Back Projects

## Overview
This document outlines the essential prerequisites for projects that feed power back into the European grid, based on EU RFG requirements and national standards.

## 1. Legal and Regulatory Prerequisites

### 1.1 Regulatory Compliance
- [ ] Understand EU Regulation 2016/631 requirements
- [ ] Review national grid code for your country
- [ ] Identify applicable generator type classification (A/B/C/D)
- [ ] Check local/regional additional requirements

### 1.2 Permits and Approvals
- [ ] Electrical installation permit
- [ ] Grid connection approval from TSO/DSO
- [ ] Environmental permits (if required)
- [ ] Building permits (for physical installations)

### 1.3 Legal Entity Requirements
- [ ] Registered business entity
- [ ] Grid connection agreement
- [ ] Energy trading licenses (if applicable)
- [ ] Insurance coverage

## 2. Technical Prerequisites

### 2.1 Generator Specifications
- [ ] Determine generator type (Type A/B/C/D)
- [ ] Maximum power output capacity
- [ ] Connection voltage level
- [ ] Technology type (solar, wind, hydro, gas, etc.)

### 2.2 Grid Connection Point
- [ ] Identify connection point on grid
- [ ] Confirm voltage level at connection point
- [ ] Assess grid capacity at connection point
- [ ] Distance from generation site to connection point

### 2.3 Technical Capabilities Required

#### For Type A & B Generators
- Active power reduction capability
- Basic frequency protection
- Basic voltage protection
- Anti-islanding protection

#### For Type C Generators (Additional)
- Frequency sensitive mode operation
- Limited frequency sensitive mode—overfrequency (LFSM-O)
- Voltage operating range compliance
- Fast fault current injection capability
- Synthetic inertia (in some jurisdictions)

#### For Type D Generators (Additional)
- Full frequency response capability
- Automatic frequency restoration reserve
- Frequency containment reserve capability
- Voltage ride-through (FRT) requirements
- High/Low voltage ride-through (HVRT/LVRT)
- Reactive power provision (0.95 leading to 0.95 lagging)
- Power oscillation damping
- SCADA and real-time monitoring

### 2.4 Protection and Control Systems
- [ ] Grid protection relay systems
- [ ] Synchronization equipment
- [ ] Anti-islanding protection
- [ ] Voltage and frequency monitoring
- [ ] Emergency shutdown systems

### 2.5 Power Quality Equipment
- [ ] Harmonic filtering (if required)
- [ ] Reactive power compensation
- [ ] Power factor correction equipment
- [ ] Voltage regulation equipment

### 2.6 Metering and Monitoring
- [ ] Bi-directional revenue-grade metering
- [ ] Real-time monitoring systems
- [ ] Data logging equipment
- [ ] Communication interfaces for grid operator

## 7. Project Timeline Considerations

### Typical Timeline Stages
1. **Pre-application (1-3 months)**
   - Feasibility assessment
   - Initial stakeholder engagement
   - Preliminary studies

2. **Application and Approval (3-12 months)**
   - Formal grid connection application
   - Detailed grid studies
   - Connection agreement negotiation

3. **Design and Procurement (6-18 months)**
   - Detailed engineering design
   - Equipment procurement
   - Certification process

4. **Construction and Installation (6-24 months)**
   - Civil works
   - Equipment installation
   - System integration

5. **Testing and Commissioning (2-6 months)**
   - Factory acceptance testing
   - Site acceptance testing
   - Compliance testing
   - Grid connection approval

## 8. Country-Specific Prerequisites

### Germany
- EEG (Renewable Energy Sources Act) compliance
- VDE-AR-N 4110/4120 technical requirements
- Bundesnetzagentur registration

### United Kingdom
- Grid Code compliance (G98/G99)
- DNO/TSO connection agreement
- Ofgem registration

### France
- CRE requirements
- ENEDIS/RTE connection procedures
- Technical specifications per voltage level

### Spain
- RD 1699/2011 compliance
- REE/distribution company requirements
- CNMC registration

### Italy
- CEI 0-16 (LV/MV) or CEI 0-21 (HV) compliance
- Terna/distribution company procedures
- GSE registration for incentives

### Netherlands
- Netcode Elektriciteit compliance
- TenneT/DSO connection requirements
- ACM registration
