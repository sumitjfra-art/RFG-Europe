# Compliance and Certification

## Overview
This document outlines the compliance and certification requirements for grid-connected generators under EU RFG regulations.

## EU RFG Compliance Framework

### Legal Basis
- **EU Regulation 2016/631**: Mandatory requirements for grid connection
- **Member State Implementation**: National grid codes implementing EU RFG
- **TSO/DSO Requirements**: Operator-specific connection conditions

### Compliance Obligation
All new generators connecting after 27 April 2019 must comply with EU 2016/631 unless exempted.

## Certification Requirements by Generator Type

### Type A Generators (≤ 0.8 kW)

#### Self-Certification
- Manufacturer's declaration of conformity
- CE marking compliance
- Basic safety standards (Low Voltage Directive)

#### Required Standards
- EN 50549-1: Low voltage generators
- IEC 61727: PV system characteristics
- IEC 62109: Inverter safety

#### Documentation
- Installation manual
- Declaration of conformity
- Technical data sheet

### Type B Generators (0.8 kW to 1 MW)

#### Extended Certification
- Manufacturer's compliance statement
- Test certificates for protection functions
- CE marking

#### Required Standards
- EN 50549-1: Low voltage generators
- IEC 61850: Communication protocols
- Protection standards as per national code

#### Testing Requirements
- Protection function tests
- Power quality measurements
- Anti-islanding verification

### Type C Generators (> 1 MW, < 110 kV)

#### Type Testing and Certification

**Mandatory Type Tests:**
1. Active power control capability
2. Frequency response (FSM/LFSM-O)
3. Reactive power capability
4. Voltage control modes
5. LVRT capability
6. Fast fault current injection
7. Protection functions
8. Power quality compliance

#### Certification Bodies
Must use accredited certification body:
- **Germany**: TÜV, VDE, DNV GL
- **UK**: DNV GL, UL, CIRED
- **France**: Bureau Veritas, LCIE
- **Spain**: LCOE, CIEMAT
- **Italy**: CESI, IMQ
- **Netherlands**: DNV GL, KEMA

#### Certification Process
1. Pre-assessment and documentation review
2. Factory acceptance testing (FAT)
3. Type testing at certified laboratory
4. Site acceptance testing (SAT)
5. Compliance verification
6. Certificate issuance

#### Documentation Required
- Detailed technical specifications
- Control system description
- Protection philosophy
- Simulation models
- Previous type certificates (if applicable)

### Type D Generators (≥ 110 kV)

#### Comprehensive Certification

**Extended Type Tests:**
All Type C tests, plus:
1. Enhanced frequency response
2. Synthetic inertia (if required)
3. HVRT capability
4. Power oscillation damping
5. Black start capability (if applicable)
6. Advanced voltage control

#### Simulation Studies Required
- Electromagnetic transient (EMT) studies
- RMS dynamic studies
- Frequency response validation
- Voltage stability analysis
- Protection coordination

#### Certification Authority
- National Regulatory Authority approval
- TSO technical approval
- Independent certification body verification

## Certification Process Steps

### 1. Pre-Certification Phase (2-4 months)

#### Activities
- Initial documentation review
- Gap analysis against RFG requirements
- Development of test plans
- Selection of certification body
- Cost estimation

#### Deliverables
- Compliance statement
- Test plan
- Documentation package
- Certification agreement

### 2. Type Testing Phase (3-6 months)

#### Factory Tests
- Equipment functional tests
- Control system validation
- Protection system verification
- Communication protocol testing
- Witness testing by certification body

#### Laboratory Tests
- Power quality measurements
- Fault ride-through tests
- Frequency response tests
- Reactive power capability
- Dynamic performance tests

#### Test Facilities
- Certified test laboratories
- Power-hardware-in-the-loop (PHIL) systems
- Real-time digital simulators (RTDS)

### 3. Site Verification Phase (1-3 months)

#### On-Site Tests
- Installation inspection
- As-built verification
- Commissioning tests
- Compliance verification tests
- Witness testing

#### Performance Validation
- Active power controllability
- Frequency response in real grid
- Reactive power provision
- Protection system operation
- SCADA communication

### 4. Certificate Issuance (1 month)

#### Final Steps
- Review of all test results
- Documentation compilation
- Certificate preparation
- Registration with authorities
- Archive of compliance records

## Required Certifications

### Electrical Safety
- **CE Marking**: EU conformity
- **Low Voltage Directive (2014/35/EU)**: LV equipment
- **IEC 61508**: Functional safety
- **IEC 62061**: Safety of machinery

### Electromagnetic Compatibility (EMC)
- **EMC Directive (2014/30/EU)**
- **EN 61000-6-4**: Emission standards
- **EN 61000-6-2**: Immunity standards

### Environmental
- **RoHS Directive**: Hazardous substances
- **WEEE Directive**: Waste electrical equipment
- **ISO 14001**: Environmental management

### Quality Management
- **ISO 9001**: Quality management system
- **ISO 50001**: Energy management (optional)

## Country-Specific Certification

### Germany

#### Certification Requirements
- VDE certification for Type C/D generators
- TAB (Technische Anschlussbedingungen) compliance
- EEG compliance certificate (for renewables)

#### Certification Bodies
- VDE Prüf- und Zertifizierungsinstitut
- TÜV Rheinland, TÜV SÜD
- DNV GL

#### Process
- Application to certification body
- Type testing as per VDE-AR-N 4110/4120
- Site commissioning
- Certificate valid for specific installation

### United Kingdom

#### Certification Requirements
- G98/G99 compliance certificate
- Engineering Recommendation G59 (older)
- Type testing per G99 requirements

#### Certification Bodies
- DNV GL
- UL
- CIRED (for research/development)

#### Process
- Type test certificate from accredited lab
- DNO/TSO connection approval
- Site commissioning
- Final connection approval

### France

#### Certification Requirements
- Compliance with RTE/ENEDIS requirements
- Type A/B: Auto-certification possible
- Type C/D: Mandatory certification

#### Certification Bodies
- Bureau Veritas
- LCIE (Laboratoire Central des Industries Électriques)

#### Process
- Pre-audit
- Type testing
- Site verification
- Certificate for PTF (connection proposal)

### Spain

#### Certification Requirements
- RD 1699/2011 compliance
- Type verification certificate
- REE/DSO approval

#### Certification Bodies
- LCOE (Laboratorio Central Oficial de Electrotecnia)
- CIEMAT
- International bodies (DNV GL, TÜV, etc.)

### Italy

#### Certification Requirements
- CEI 0-16 or CEI 0-21 compliance
- Type testing certificate
- TICA approval (connection)

#### Certification Bodies
- CESI
- IMQ (Istituto Italiano del Marchio di Qualità)
- International bodies (authorized)

### Netherlands

#### Certification Requirements
- Netcode compliance
- Type testing certificate
- TenneT/DSO approval

#### Certification Bodies
- DNV GL
- KEMA Laboratories
- TÜV

## Compliance Testing Standards

### IEC Standards
- **IEC 61400**: Wind turbine standards
- **IEC 61727**: PV system characteristics
- **IEC 61850**: Substation automation
- **IEC 60909**: Short-circuit calculations
- **IEC 61000**: EMC standards

### EN Standards
- **EN 50549**: Connection of generators to LV
- **EN 50438**: Micro-generators (older)
- **EN 61000**: EMC harmonized standards

### IEEE Standards (Reference)
- **IEEE 1547**: Interconnection standards
- **IEEE 519**: Harmonic control

## Testing Equipment and Facilities

### Required Test Equipment
- Power quality analyzers
- Protection relay test sets
- Frequency response analyzers
- LVRT/HVRT test systems
- SCADA simulation tools

### Test Laboratories in Europe
- **DNV GL Energy Labs** (Multiple locations)

## Costs of Certification

### Typical Cost Ranges

#### Type A/B Generators
- Self-certification: €500 - €2,000
- Basic testing: €2,000 - €10,000

#### Type C Generators
- Pre-assessment: €5,000 - €15,000
- Type testing: €50,000 - €150,000
- Site verification: €10,000 - €30,000
- **Total**: €65,000 - €195,000

#### Type D Generators
- Pre-assessment: €20,000 - €50,000
- Type testing: €150,000 - €500,000
- Simulation studies: €50,000 - €200,000
- Site verification: €30,000 - €100,000
- **Total**: €250,000 - €850,000

### Additional Costs
- Repeat testing (if failures): 50% of initial test costs
- Certificate maintenance: €5,000 - €20,000 annually
- Modified design re-certification: 30-50% of initial costs

## Maintaining Compliance

### Ongoing Requirements
- Periodic testing and inspection
- Protection settings review
- Firmware/software updates validation
- Performance monitoring
- Incident reporting

### Re-Certification Triggers
- Major equipment modifications
- Control system changes
- Protection scheme changes
- Significant performance deviations
- Regulatory changes

### Audit and Inspection
- TSO/DSO periodic audits
- Random compliance checks
- Post-incident investigations
- Annual performance reviews

## Non-Compliance Consequences

### Potential Issues
- Connection refusal
- Disconnection from grid
- Financial penalties
- Loss of incentives/subsidies
- Legal liability for grid disturbances

### Remediation
- Immediate corrective actions
- Re-testing and re-certification
- Temporary disconnection
- Operational restrictions
- Enhanced monitoring period
