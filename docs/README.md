## Quick Start
If you're starting a grid feeding back project in Europe, begin with:
1. Review the [Prerequisites](prerequisites.md) document
2. Understand the applicable [European RFG Standards](european-rfg-standards.md)
3. Check [Grid Connection Requirements](grid-connection-requirements.md) for your specific country
4. Review [Technical Specifications](technical-specifications.md) for your project type
5. Ensure [Compliance](compliance-certification.md) with all relevant regulations

## About RFG
RFG (Requirements for Generators) establishes network code on requirements for grid connection of generators to ensure the secure operation of the European electricity system. This is primarily governed by EU Regulation 2016/631.
