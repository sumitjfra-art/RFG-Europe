# European RFG Standards Overview

## EU Regulation 2016/631
The main European regulation governing Requirements for Generators is **Commission Regulation (EU) 2016/631** establishing a network code on requirements for grid connection of generators.

### Official Document
- **Full Title**: Commission Regulation (EU) 2016/631 of 14 April 2016
- **EUR-Lex Link**: https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32016R0631
- **Publication Date**: 14 April 2016
- **Entry into Force**: 17 May 2016

### Scope
This regulation applies to:
- Synchronous power-generating modules
- Power park modules (wind and solar)
- Offshore power park modules
- Demand facilities
- Transmission-connected distribution facilities
- Closed distribution systems
- HVDC systems

## Key European Standards

### ENTSO-E Requirements
The European Network of Transmission System Operators for Electricity (ENTSO-E) provides:
- Network codes and guidelines
- Implementation guidance
- Technical standards

**ENTSO-E Website**: https://www.entsoe.eu/

### Generator Types Classification

#### Type A: Small Generators
- Connection voltage < 110 kV
- Maximum capacity: ≤ 0.8 kW per connection point

#### Type B: Medium Generators
- Connection voltage < 110 kV
- Capacity: > Type A threshold to ≤ 1 MW

#### Type C: Large Generators
- Connection voltage < 110 kV
- Capacity: > 1 MW

#### Type D: Very Large Generators
- Connection voltage ≥ 110 kV
- All capacities at transmission level

## Regional Variations
Member states may implement additional requirements:
- National grid codes
- TSO-specific requirements
- Regional specifications

## Important Aspects Covered

### 1. Frequency Stability
- Frequency ranges for operation
- Rate of change of frequency (ROCOF)
- Frequency response capabilities

### 2. Voltage Requirements
- Voltage range operation
- Reactive power capability
- Voltage ride-through capabilities

### 3. System Protection
- Fault ride-through requirements
- Protection settings
- Island operation prevention

### 4. Power Quality
- Harmonics and flicker limits
- Active power controllability
- Reactive power provision

### 5. Communication and Control
- Real-time data provision
- Remote control capabilities
- SCADA integration
