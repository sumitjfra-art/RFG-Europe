## What is RFG?

Requirements for Generators (RFG) is the EU network code establishing requirements for grid connection of generators to ensure secure operation of the European electricity system. It is governed by **EU Regulation 2016/631**.

### Generator Types

| Type | Voltage Level | Capacity | Requirements |
|------|---------------|----------|--------------|
| Type A | < 110 kV | ≤ 0.8 kW | Basic protection, anti-islanding |
| Type B | < 110 kV | 0.8 kW - 1 MW | Enhanced protection, frequency response |
| Type C | < 110 kV | > 1 MW | FSM/LFSM-O, LVRT, reactive power capability |
| Type D | ≥ 110 kV | All capacities | Full frequency response, HVRT, advanced control |
